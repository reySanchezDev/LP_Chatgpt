**Repositorio de transferencia a Codex.** Referencia visual y funcional autorizada: [sitio publicado](https://la-sazon-de-sheyla-nindiri.gracefulglobe8.chatgpt.site/).

> **Estado verificable (2026-11-21):** este repositorio contiene instrucciones y recursos originales recuperados del Google Drive del negocio. **Aún no contiene el código fuente del sitio publicado.** La URL de ChatGPT Sites no permitió recuperar su HTML/CSS/JS desde la sesión que creó esta transferencia. No considerar este repositorio una copia funcional del sitio hasta que Codex exporte los archivos originales y complete la conversión.

## Objetivo

Migrar el diseño aprobado **con paridad visual y funcional** a un proyecto Astro real. No reinterpretar, rediseñar ni sustituir imágenes por imágenes inventadas. **Primero exportar el código del proyecto original desde ChatGPT Sites**, luego trasladar componentes, estilos, recursos y animaciones, y por último comparar con la versión publicada.

## Estructura de transferencia

- `assets/originales/`: logotipo PNG transparente y JPG del negocio.
- `assets/fotografias/`: fotografías de productos y portada tomadas de la carpeta original de Drive.
- `docs/`: especificación para reproducir **la versión publicada**, no una propuesta nueva.

Cuando se pueda exportar el código, crear la aplicación Astro en la raíz del repositorio respetando estas referencias; usar `public/` para los recursos que sirva el sitio y conservar `assets/originales/` como copia inalterada.

**Fuente principal:** ChatGPT Sites publicado. **Fuente secundaria:** archivos originales de Drive. Si hay diferencias, escalar el punto preciso; no improvisar la UI.
